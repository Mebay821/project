# WATER QUEUE
This project helps inform residents on current tap-water flow status, water-related pricing guides and resource-conservation tips. It also contains interactive panels that help residents address issues they may face. 
## INCLUDED PAGES:
* HOME 
* DASHBOARD 
* PRICING GUIDE
* RESOURCE CONSERVATION
* ABOUT PROJECT
## FEATURES
* Current flow-status
* Usage charge
* Interactive-panels
## LANGUAGES
*HTML
*CSS
*JAVASCRIPT
